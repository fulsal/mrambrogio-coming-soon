# Mr. Ambrogio — Coming Soon

Static landing page for `www.mrambrogio.com`.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `mrambrogio-coming-soon`.
2. Upload the four files from this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Set the custom domain to `www.mrambrogio.com` if GitHub does not detect the included `CNAME` file automatically.
